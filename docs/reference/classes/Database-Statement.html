Fetches the next row from a result set.

public fetch([int $mode = PDO::FETCH_DEFAULT ][, int $cursorOrientation = PDO::FETCH_ORI_NEXT ][, int $cursorOffset = 0 ]) : mixed

\PDOStatement::fetchColumn(); will return false. This method will make sure NULL may be return instead.

Parameters
$mode : int = PDO::FETCH_DEFAULT

(optional) Controls how the next row will be returned to the caller. This value must be one of the PDO::FETCH_* constants, defaulting to value of PDO::ATTR_DEFAULT_FETCH_MODE (which defaults to PDO::FETCH_BOTH).

$cursorOrientation : int = PDO::FETCH_ORI_NEXT

(optional) For a PDOStatement object representing a scrollable cursor, this value determines which row will be returned to the caller. This value must be one of the PDO::FETCH_ORI_* constants, defaulting to PDO::FETCH_ORI_NEXT. To request a scrollable cursor for your PDOStatement object, you must set the PDO::ATTR_CURSOR attribute to PDO::CURSOR_SCROLL when you prepare the SQL statement with PDO::prepare.

$cursorOffset : int = 0

(optional)
